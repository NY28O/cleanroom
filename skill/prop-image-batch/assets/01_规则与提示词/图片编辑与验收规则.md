# 原画布恢复稿验收

检查对象是 `恢复图/` 中的同名透明 PNG，`raw/` 是只读的高清原稿。生成后只允许等比缩放一次并对位，不调色、不补线；恢复时保留生成稿的 RGB 颜色和材质，使用原图 Alpha 作为最终透明边缘与镂空。

| 项目 | 通过条件 |
| --- | --- |
| 文件与摆放 | 单帧、同名、原宽高、真实透明 PNG；可见主体、留白、支点、数量、孔洞和半透明轮廓均与原图对应。原尺寸与 Alpha 逐像素核验通过才能作为替换稿。 |
| 线条 | 在目标显示尺寸查看斜线、圆弧、轮缘和小孔：外轮廓细黑，过渡自然，无阶梯、白边、断线或双边；内部线比外缘柔和。浅底和深底都要看。 |
| 配色与画风 | 主辅色符合用途，明显区别于原图，同款多视图配色一致。大片中低饱和，小面积点色；暖柔光、平滑色面，无可见彩铅和纸粒，材质与内部结构清楚。详见[最终效果约束](最终效果约束.md)。 |

**原尺寸为硬性条件。** 以解码后的 PNG 为准，宽、高有任一项相差 1 像素即退回；同宽高再逐像素比较 Alpha。逐像素不一致单列为轮廓未过；尺寸通过不能代替整体验收。

**判定：** 技术通过登记「待验收」，外观通过并经人工放行后原样入库。尺寸不符登记实际宽高和「仅供看样」；尺寸不同不能声称轮廓逐像素一致。透明度、对位或画风不合格时保留原因，不通过本地修图补足。

检查批次内的 `恢复核验.json`：`overlap` 和 `aligned_alpha_different_pixels` 是使用原图 Alpha **前**的对位结果，`alpha_different_pixels` 是写入后重新解码的差异数。主体重叠率低于 0.85 转人工复核，不能因最终 Alpha 相同而放行。
