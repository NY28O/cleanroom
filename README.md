# 道具图批量修图

安装目录为 [skill/prop-image-batch](skill/prop-image-batch/SKILL.md)。从仓库下载或解压交付包后，把整个 `prop-image-batch` 文件夹复制到自己的技能安装目录（Codex：`~/.codex/skills/`）；也可以直接使用解压目录中的脚本。

按[使用说明](skill/prop-image-batch/references/usage.md)安装依赖、指定自己的原图库和组号、查看代表图并分组验收入库。仅预检不需要密钥；联网出图前先按[环境配置](skill/prop-image-batch/references/setup.md)填写自己的服务地址和密钥。
