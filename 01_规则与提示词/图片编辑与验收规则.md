# 统一绘本风格：图片编辑与验收

画风依据[新风格参考提示词](../新风格参考提示词.md)，逐张编辑使用[正式提示词](温暖家居_编辑提示词.txt)。以待验收图对应的原图检查摆放、边缘及镂空。

| 原尺寸下看什么 | 通过条件 |
| --- | --- |
| 线条与造型 | 黑色细描边略有手绘起伏，轮廓圆润可读。外轮廓使用纯黑 #000000 细线，保留类别、数量和特征。 |
| 光影与材质 | 暖漫射光、低反差、轻薄柔影；水彩晕染、彩铅和纸面颗粒在主体上可辨。布、木、玻璃和天然物各自像原来的材质。 |
| 饱和度 | 在原尺寸白底和深灰底下并排看，主辅色柔和而可辨，较鲜颜色仅作小面积点缀。大面积刺眼、荧光感、靠提饱和度制造色差，或降色后水彩层次发灰，均退回调整。 |
| 成组效果 | 同组共用笔触、光感和材质画法，同款不同视图配色一致，不同变体仍能区分。每款须选取合常识、明显不同于原图的主辅色；在原尺寸下能一眼区分。款式变化仅限轮廓内部。 |
| 摆放与对位 | 原尺寸下切换原图和恢复图，支点、折弯、悬垂方向、遮挡、位置和占用范围对得上。最终画布和 Alpha 与对应原图逐像素一致，包括外缘、孔洞及半透明边；明显平移、缩放、拉伸或改变接触关系则退回。 |
| 文件与透明度 | 单帧、同名、原宽高 PNG，主体可见；主体外完全透明，镂空通透，抗锯齿边缘自然。用白底、深底和棋盘底检查白边、残雾、封孔和假背景。 |

先检查新图结构能否可靠对位，再沿原轮廓完成内部改款。使用默认严格模式比较原图和最终 PNG 的 Alpha；并排核对各色区、黑线、内部结构、镂空和边缘，拒收错位、双边或穿帮。颜色只改明度、滤镜或小点缀不能通过。外缘有透明像素只是技术检查，不代表摆放、镂空和画风合格。技术检查与外观复核均通过后才作为正式成品；异常稿记录原因并保留原始返回。
